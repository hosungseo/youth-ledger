# 청년대장

온통청년에 등록된 청년정책과 예산서(지방재정365·열린재정)에 잡힌 청년 세부사업을 한자리에서 견주는
비공식 개념검증(PoC) 사이트입니다. 창업대장(changup.seohosung.com)의 틀을 청년정책에 옮겼습니다.

- 온통청년 기준: 청년정책 2,914건을 지역 × 분야 판, 목록, 분야, 정책 상세(보조금24·예산 연결)로
- 재정 기준: 청년 세부사업 6,143건(지방 6,109 · 중앙 34), 온통청년 등록 여부, 부문, 집행 추이
- 연결 정확도는 표본 블라인드 검토로 측정해 자료 페이지에 적었습니다

자료: 온통청년 공개 정책검색, 공공데이터포털 「행정안전부_대한민국 공공서비스(혜택) 정보」,
지방재정365 세부사업별 세출현황, 열린재정 세부사업 일별 집행현황 (2026-09 기준).
담당자 성명·연락처 등 개인 관련 항목은 싣지 않았습니다. 기관의 공식 입장이 아닙니다.
